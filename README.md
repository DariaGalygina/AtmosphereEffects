# Интерактивный 3D-ландшафт с динамической сменой погоды и атмосферными явлениями

## Обзор

Проект представляет собой интерактивное 3D-приложение на C++ и OpenGL, визуализирующее процедурно сгенерированный ландшафт с динамическими погодными системами, циклом смены дня и ночи, а также атмосферными эффектами.

## Возможности

- Процедурная генерация ландшафта на основе карты высот с текстурным смешиванием по высоте
- Динамические системы частиц для снега и дождя с физикой движения (гравитация, ветер, случайные отклонения)
- Анимированный туман с неоднородной плотностью на основе многослойного шума
- Рекурсивная генерация молний с ветвлением и эффектом предварительных вспышек
- Цикл смены дня и ночи с движением солнца, изменением цвета неба и звёздным небом
- Интерактивное управление камерой и переключение погодных режимов через клавиатуру
- 3D-модель луны с текстурой 

## Системные требования

- Операционная система: Windows 10/11
- Компилятор: Visual Studio 2022 (MSVC)
- Видеокарта: с поддержкой OpenGL 3.3
- Разрешение экрана: 1280×720 или выше (рекомендуется Full HD)

## Управление

| Действие | Клавиши |
|----------|---------|
| Движение камеры | `W` `A` `S` `D` |
| Подъём / опускание камеры | `Space` / `Left Shift` |
| Поворот камеры | Мышь |
| Включение снега | `Ctrl` + `1` |
| Включение дождя | `Ctrl` + `2` |
| Включение тумана | `Ctrl` + `3` |
| Включение молний | `Ctrl` + `5` |
| Включение солнца | `Ctrl` + `6` |
| Режим «Звёзды» | `Ctrl` + `7` |
| Плотность осадков | `↑` / `↓` |
| Плотность тумана | `[` / `]` |
| Скорость смены дня/ночи | `KP8` / `KP2` |
| Масштаб текстур | `X` / `Z` |
| Полноэкранный режим | `F12` |
| Выход | `Esc` |

## Сборка и запуск

1. Открыть `work_krs.sln` в Visual Studio 2022
2. Убедиться, что зависимости (GLFW, GLAD, GLM) настроены корректно
3. Собрать проект (`Ctrl+Shift+B`)
4. Запустить приложение (`F5` или `Ctrl+F5`)

## Ключевые особенности

### Генерация ландшафта
- Построение сетки на основе карты высот
- Расчёт нормалей для корректного освещения
- Наложение текстур по высоте с плавными переходами

### Системы частиц
- **Снег:** 8000 частиц с гравитацией, ветром, раскачиванием и вращением
- **Дождь:** 15000 частиц с высокой скоростью падения, шлейфом и случайными вариациями

### Атмосферные эффекты
- **Туман:** анимированная неоднородная плотность на основе многослойного шума
- **Молнии:** рекурсивная генерация разрядов с ветвлением и предварительными вспышками
- **Солнце:** светящаяся сфера с размытыми границами, цвет меняется от оранжевого к белому

### Небо и небесные тела
- Динамический цвет неба в зависимости от угла солнца
- Процедурные звёзды с мерцанием
- 3D-сфера луны с эффектом свечения
